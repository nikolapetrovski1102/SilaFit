Access is enforced by the API
This page is only served at all when the request carries a valid two-factor session; the password and authenticator code are checked server-side against a PBKDF2 hash and a TOTP secret, never in the browser.
Deletion guards

Deletes run through the API against the live database, not a local copy. An exercise still used by a split day, a plan with active subscribers, or a split with active users is refused rather than silently broken — the console shows the API's reason when that happens.
